ClaudeTalk — 多 Channel Bot 架构

Feishu · DingTalk · Discord · MCP · feishu-bridge · peer-message IPC

Channel 架构

  • 3 channel: Feishu / DingTalk / Discord
  • registry.ts 自注册模式，新增无需改核心
  • feishu-bridge 作为独立 bot 桥接外部消息
  • feishu-shared library 两方共用

3-Bot 通信

  • peer-message 文件 IPC (bot_claudetalk.json)
  • feishu-bridge: /twin → twin, /trip → trip
  • 每 bot 独立 CC 子进程 (claude.ts + proc.ts)
  • twin → digital-clone MCP, trip → travel-mcp

Core 能力

  • 消息分类路由 (classifier.ts)
  • 身份/权限校验 (identity.ts + permission.ts)
  • 数字分身交互 (twin-interactions.ts)
  • steps摘要 + 后台任务 + 通话归档
